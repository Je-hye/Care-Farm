# 5. 비즈니스 모델 및 수익 구조 — 임팩트 중심안 (Impact-oriented Business Model)

> 이 문서는 `docs/business-model.md`(OEM 제조안), `docs/business-model-small-batch.md`(소규모 직접 제작안)와 별개의 **대안 BM**이다. 목적을 이익 극대화가 아니라 **혈액투석 환자의 성분 정보 접근성과 간식 선택권 개선**에 두고, 판매 수익과 후원·지원금을 섞어 운영한다. 팀이 졸업하면 운영을 이어가기 어렵다고 보고, **졸업 시점에 기존 기업·기관·단체가 이어받을 수 있는 상태로 넘기는 것(이관)을 출구로 전제한다.** 수치는 모두 `가정`이며 인터뷰·견적·지원사업 조건 확인 후 교체한다.

## 한 줄 요약

**판매로 운영비를 점차 충당하면서, 부족분은 지원사업·후원으로 메우고, 성과는 수익이 아니라 임팩트 지표로 평가한다. 그리고 졸업 전에 레시피·성분 기준·검증 데이터를 정리해 이어받을 곳에 넘긴다.** 직접 제작 판매 단독으로는 이익이 거의 나지 않으므로, 이 안은 후원·지원 자금과 기관 연계가 있을 때만 성립하며 팀의 자립 운영은 목표가 아니다.

## 1. 문제와 수혜자

| 구분 | 내용 |
|---|---|
| 해결할 문제 | 혈액투석 환자와 보호자는 간식 선택 시 나트륨·칼륨·인 정보를 찾기 어렵고, 먹는 양을 계산하기 어려워 간식을 포기하거나 불안하게 선택한다 |
| 문제의 크기 근거 | 신장질환 발생 후 가장 힘든 점 1위가 식단관리(43.8%), 등록 투석환자 중 65세 이상 59.8% (2025 광주시 신장장애인 실태조사 / KORDS 2024) |
| 1차 수혜자 | 혈액투석 환자 (특히 고령 환자) |
| 2차 수혜자 | 환자를 돌보는 가족·보호자, 투석센터·요양시설 |
| 임팩트의 범위 | **성분 정보 접근성, 선택권, 식생활 만족도.** 혈액 검사 수치 개선 등 건강 결과는 목표로 삼거나 주장하지 않는다 |

## 2. 임팩트 구조 (투입 → 활동 → 산출 → 성과)

| 단계 | 내용 |
|---|---|
| 투입 | 지원금·후원금, 영양사 자문, 공유주방, 팀 시간 |
| 활동 | 성분 설계·검사, 사과 쌀쿠키 소량 제작, 환자·보호자 인터뷰, 투석센터·환우회 연계, 포장 정보 설계(큰 글씨·간단한 표) |
| 산출 | 성분 검사 결과가 공개된 제품, 1개당 성분 표기 포장, 판매·배송 건수, 연계 센터 수 |
| 단기 성과 | 환자가 성분 정보를 쉽게 찾고 이해함, 간식 선택에 대한 불안·포기 경험 감소 |
| 중기 성과 | 반복 이용(재구매), 센터·환우회를 통한 확산, 후원자·지원기관의 지속 참여 |

## 3. 임팩트 지표

| 구분 | 지표 | 목표 (제안) | 측정 방법 |
|---|---|---|---|
| 도달 | 활성 이용 환자 수 (월 1회 이상 구매) | 1년차 30~60명 | 주문·정기배송 기록 |
| 도달 | 연계 투석센터·환우회 수 | 1년차 2곳 이상 | 협약·소개 기록 |
| 접근성 | 성분정보 이해도 (포장을 보고 1개당 주요 성분 함량을 정확히 찾은 비율) | 80% 이상 | 파일럿 평가 |
| 선택권 | "이 제품 덕분에 간식 선택이 쉬워졌다"에 동의하는 비율 | 70% 이상 | 구매 후 설문 (전후 비교) |
| 불안 감소 | 간식 선택 시 불안·포기 경험 (5점 척도 전후 비교) | 평균 1점 이상 개선 | 구매 전·후 설문 |
| 신뢰 | 영양사 감수와 성분 검사 결과 공개 비율 | 100% | 제품별 기록 |
| 지속 | 8주 재구매율 | 30% 이상 | 첫 유료 구매 후 56일 이내 재구매 |
| 만족 | 맛 만족도 | 평균 4점/5점 이상 | 시식 평가 |

수치는 제안값이며 파일럿 결과로 조정한다. 설문은 구매 전 기준값을 먼저 받고, 일정 기간 후 같은 질문을 반복한다.

## 4. 협력 기관 (후보, 미접촉)

| 구분 | 역할 | 확인할 것 |
|---|---|---|
| 환우회·신장장애인 단체 | 인터뷰·시식 참여, 소개, 임팩트 설문 협조 | 지역 단체 소재와 연락처, 협조 조건 |
| 투석센터·병원 영양팀 | 환자 소개, 간식 섭취 규정 안내 | 센터 내 간식·시식 허용 여부, 소개 절차 |
| 임상영양사 | 성분 목표 감수, 표시 표현 검토 | 감수 범위·사례비 |
| 경북대 창업지원단·관련 학과 | 지원금 연계, 영양·식품 자문 | 지원 조건과 집행 규정 |
| 지역 사회적경제 지원기관 | 소셜벤처·사회적기업 지원 연계 | 인증·지원 조건 (미확인) |
| 공유주방·제조처 | 소량 제작 공간, 향후 위탁 생산 | 영업 신고 가능 시설, 요금, 최소 주문량 |

## 4-1. 이관 계획 (졸업 후)

팀이 떠난 뒤에도 사회적 가치가 이어지도록, 이어받는 쪽이 바로 운영할 수 있는 자산과 권리를 정리해 넘긴다.

### 넘길 자산

| 자산 | 내용 |
|---|---|
| 성분 설계 기준 | 나트륨·칼륨·인 목표와 근거, 영양사 감수 기록 |
| 레시피·배합표 | 사과 쌀쿠키 레시피와 제조 공정 조건 |
| 성분 검사 데이터 | 검사 결과, 검사기관, 표시 양식 |
| 고객 검증 자료 | 인터뷰·프리오더·설문 결과, 가격 반응, 재구매 데이터 |
| 포장·정보 설계 | 큰 글씨·간단한 표 등 정보 표기 방식 |
| 협력 네트워크 | 환우회·투석센터·영양사·제조처 관계와 연락 기록 |

### 이관 상대와 방식 (후보, 미접촉)

| 상대 | 방식 |
|---|---|
| 기존 식품 제조사 | 레시피·성분 기준 라이선스 또는 기술 이전, 공동 브랜드 운영 |
| 투석센터·요양시설 운영 법인 | 납품용 간식 개발 방식을 전수해 자체 운영 |
| 환우회·재단 등 비영리 단체 | 가이드와 레시피를 이관해 그쪽이 운영 |
| 후배 팀·창업동아리 | 동아리 안에서 승계 |

### 권리 정리 체크리스트

| 항목 | 확인할 것 |
|---|---|
| 지원금 결과물의 권리 | 지원사업별 지식재산권 귀속 조건과 이관 가능 여부 |
| 제조처 협업 | 레시피·배합표 소유권, 제3자 이전 가능 여부를 계약서에 명시 |
| 상표·브랜드 | 브랜드명 사용권과 이전 방법 |
| 데이터 | 인터뷰·설문의 개인정보 제거와 이관 범위 동의 |
| 영양사 감수 | 감수 내용의 사용·이전 범위 |

### 이관 준비도 지표

| 지표 | 목표 (제안) | 시점 |
|---|---|---|
| 자산 문서화 완료율 (위 6개 자산 중 정리된 비율) | 100% | 졸업 6개월 전 |
| 이관 상대 후보와 협의 진행 | 1곳 이상 | 졸업 6개월 전 |
| 권리 관계 정리 | 지원금·제조처·상표·데이터 항목 모두 확인 | 졸업 6개월 전 |
| 인수인계 매뉴얼 (제작·검사·판매·고객 응대) | 작성 완료 | 졸업 3개월 전 |

## 5. 혼합 수익 구조

| 층 | 재원 | 용도 | 비중 목표 (제안) |
|---|---|---|---|
| ① 제품 판매 | 일반구매 14,900원, 정기배송 13,900원 (배송비 3,000원 별도) | 변동원가와 운영비 | 1년차 운영비의 약 50%, 3년차 80% 이상 |
| ② 지원사업·공모 | 창업동아리·소셜벤처·사회공헌 공모 지원금 | 성분 분석, 시제품, 검증, 초기 운영 | 1년차 중심 |
| ③ 후원·기부 | 기업 후원, 개인 후원, 후원형 크라우드펀딩 | 나눔 판매, 임팩트 측정, 운영 보조 | 보조 |
| ④ 기관 연계 | 센터·시설 단체 구매·정기 공급 (개당 1,400~1,500원 수준 가정) | 반복 매출과 도달 확대 | 이관 이후 상대가 운영하는 경우 포함 |
| ⑤ 이관 대가 (선택) | 라이선스·기술 이전 대가 또는 이어받는 곳의 운영 지원 | 규모는 협의. 목적은 수익이 아니라 가치의 지속 | 졸업 시점 |

### 판매 수익이 운영비를 얼마나 덮는가 (월 고정비 130만 원, 세트당 평균 공헌이익 약 6,618원 가정)

| 월 판매 | 판매 공헌이익 | 운영비 충당률 | 후원·지원 필요액 (월) | 활성 환자 수 추정 |
|---|---|---|---|---|
| 50세트 | 약 33만 원 | 약 25% | 약 97만 원 | 약 15~30명 |
| 100세트 | 약 66만 원 | 약 51% | 약 64만 원 | 약 30~60명 |
| 150세트 | 약 99만 원 | 약 76% | 약 31만 원 | 약 45~95명 |
| 196세트 | 약 130만 원 | 100% | 0원 | 약 60~120명 |

- 활성 환자 수는 환자 1명이 월 1.6~3.3세트(투석 주 3회, 투석마다 간식 1~2개 가정)를 쓴다는 가정이다.
- 월 100세트일 때 연 후원·지원 필요액은 약 770만 원이며, 활성 환자 1명당 월 약 1.1~2.1만 원이다.
- 세트당 공헌이익은 직접 제작 기준안(개당 변동원가 900원, 부가세 2%, 수수료 4%) 평균값이다.

### 나눔 판매 (선택)

구매 10세트당 1세트를 환우회·취약 환자에게 기부하는 구조이다. 월 100세트 판매 시 기부 10세트의 변동원가는 약 7만 원(세트당 약 7,200원 가정)이다. 후원금이 이 비용을 충당하면 구매자에게 "나눔에 참여하는 구매"라는 가치를 줄 수 있다. 환자 대상 기부는 개인정보와 배분 기준을 사전에 정한다.

## 6. 초기 비용 (500만 원 목표 예산)

| 항목 | 예산 |
|---|---|
| 핵심 성분 분석·전문 검토 | 120만 원 |
| 시제품·소량 제작 (재료·포장·공간 대여) | 50만 원 |
| 고객 파일럿·프리오더·임팩트 설문 운영 | 50만 원 |
| 영업 신고·위생교육·통신판매업 신고 | 20만 원 |
| 포장 샘플·제품 설명자료 | 30만 원 |
| 운영 손실 한도 (판매로 못 덮는 고정비) | 230만 원 |
| **합계** | **500만 원** |

500만 원은 확보된 자금이 아닌 목표 예산이며, 지원사업 선정과 집행 조건에 따라 조정한다. 공유주방 요금, 신고 비용, 검사 견적은 확인 후 교체한다.

## 7. 단계

| 단계 | 기간 | 내용 | 다음 단계 조건 |
|---|---|---|---|
| 1. 검증·기준값 | 3주 | 인터뷰, 영양사 검토, 보건소 확인, 사전 신청, 임팩트 설문 기준값 수집 | 구매 의향 과반, 사전 신청 30세트 이상, 영업 신고 가능, 협력 기관 1곳 이상 |
| 2. 소량 판매·임팩트 측정 | 출시 후 0~6개월 | 직접 제작 판매, 센터·환우회 연계, 전후 설문 | 이해도 80% 이상, 재구매율 30% 이상 |
| 3. 이관 준비 | 졸업 6개월 전부터 | 자산 문서화, 권리 정리, 이관 상대 후보와 협의, 인수인계 매뉴얼 작성 | 이관 준비도 지표 달성 |
| 4. 이관 실행 | 졸업 시점 | 이관 상대에 자산·권리·운영 인계 | 인계 완료, 이관 후 3개월 연락 유지 |

## 8. 중단·재설계 기준

| 항목 | 기준 |
|---|---|
| 수요 | 구매 의향이 과반 미만이거나 사전 신청 15세트 미만이면 중단 |
| 임팩트 | 이해도 80% 미만이면 포장·정보 설계를 개선하고 재평가, 재미달 시 재설계 |
| 협력 | 3개월 안에 협력 기관(센터·환우회) 1곳도 확보하지 못하면 도달 계획을 재설계 |
| 자금 | 운영 손실이 한도(230만 원)에 닿으면 판매 성과와 관계없이 중단 여부 재판단 |
| 후원 의존 | 후원·지원이 운영비의 80% 이상인 상태가 1년 넘게 지속되면 이관 시점을 앞당기거나 규모를 줄임 |
| 이관 | 졸업 6개월 전까지 이관 상대 후보 1곳과도 협의하지 못하면 판매를 접고 자료 정리·공개 방식(가이드·데이터 공유)으로 전환 |

## 9. 리스크 및 확인 사항

| 구분 | 내용 | 대응 |
|---|---|---|
| 임팩트 과장 | 건강 개선 효과를 내세우면 식품 광고 규제와 충돌 | 임팩트를 "성분 정보 접근성·선택권"으로 한정, 허용 표현은 식품의약품안전처·관할 보건소에서 확인 |
| 측정 부담 | 전후 설문과 추적이 팀 부담이 될 수 있음 | 설문 문항을 5개 이내로 단순화, 구매·재구매 기록과 연동 |
| 환자 대상 활동 | 개인정보, 사전 검토 필요 | 최소 정보 수집, 동의, 의료 조언 금지 |
| 후원·기부 처리 | 사업자 형태에 따라 후원금 수령·영수증·세무 처리가 달라짐 | 사업자 형태(개인사업자·법인·협동조합·사회적기업 인증 등)와 후원 처리 방식을 세무사·관할 기관에서 확인 |
| 지원금 집행 조건 | 재고·인건비 등 집행 불가 항목 가능 | 공모별 집행 조건을 먼저 확인하고 예산 항목 배분 |
| 판매량·원가 | 직접 제작 단독으로는 이익이 거의 없음 | 소규모 직접 제작안의 시나리오·제조처 이전 조건을 따른다 |
| 영업 신고·시설 | 직접 제작·판매에 필요한 신고 업종 미확인 | 보건소 확인 후 신고 가능한 시설 계약 |
| 의존 | 지원·후원 의존이 커지면 지속성이 약해짐 | 운영비 충당률 목표와 후원 의존 기준 관리 |
| 이관 실패 | 졸업 시점에 이어받는 곳이 없으면 가치가 사라짐. 레시피 소유권이 불분명하면 넘길 수 없음 | 권리 정리 체크리스트, 이관 상대 조기 접촉, 자료 문서화 |

## 10. 지표 산정 기준

| 지표 | 산정 방식 |
|---|---|
| 활성 이용 환자 수 | 해당 월 유료 구매가 있는 환자·보호자 고객 수 (무료 시식 제외) |
| 성분정보 이해도 | 포장을 보고 1개당 주요 성분 함량을 정확히 찾은 참여자 수 ÷ 평가 참여자 수 |
| 선택권·불안 감소 | 구매 전 기준 설문과 구매 후 설문의 응답을 같은 사람 기준으로 비교 |
| 8주 재구매율 | 첫 유료 구매 후 56일 이내 재구매 고객 수 ÷ 56일 관찰이 끝난 첫 구매 고객 수 |
| 운영비 충당률 | 판매 공헌이익 ÷ 월 고정비 |
| 세트당 공헌이익 | 판매가 − 부가세 − 결제수수료 − 변동원가 (배송비는 구매자 부담) |
