# 3주 검증 계획 (2026-10-06 ~ 10-26)

**목적:** 돈을 쓰기 전에 ① 환자·보호자가 이 간식을 살 이유가 있는지, ② 제조 조건이 맞는지, ③ 가격에 실제 구매 의사가 있는지를 확인하고, 10월 26일에 **진행 / 보류 / 중단**을 결정한다. 결과는 HERO IR(11/2) 자료에 반영한다.
**비용 상한:** 약 50만 원 (시제품 소량 직접 제작 30만 + 사례품·자료 20만, 제안값). 이 범위를 넘으면 진행하지 않는다.

|---|---|---|---|

| 2주 | 10/13~10/19 | 환자·보호자 인터뷰 진행 · 영양사 1~2명 검토 · 제조사 회신 수집 · 사전 신청 페이지 공개(가격 A/B) | 인터뷰 기록, 제조사 회신표 |

## 인터뷰 대상

| 대상 | 인원 | 확인할 내용 |
|---|---|---|
| 혈액투석 환자 | 8~10명 | 간식 구매·포기 경험, 필요한 성분 정보, 지금 쓰는 대체품 |
| 보호자 | 약 5명 | 실제 결제자, 구매 기준, 지불 가능 가격 |
| 영양사 | 1~2명 | 성분 목표 현실성(나트륨·칼륨·인), 표시 시 주의점 |
| 투석센터·요양시설 담당자 | 1~2곳 | 환자에게 간식 소개 가능 여부, 소개 절차 |

섭외 경로는 투석센터 소개, 환우 커뮤니티(운영 규정 확인), 인터뷰 대상자 소개이다. 환자 대상 인터뷰는 필요한 사전 검토 후 진행하며, 의료적 조언이나 치료 효과를 말하지 않는다.

**핵심 질문 5가지**
1. 지금 어떤 간식을 먹고, 못 먹어서 포기한 적이 있는가?
2. 성분 정보(나트륨·칼륨·인)를 어디서 어떻게 확인하는가?
3. 누가 사고, 한 번에 얼마까지 쓰는가?
4. 8개입 14,900원 (또는 13,900원)이면 사겠는가? 얼마부터 부담스러운가?
5. 이 제품을 사려면 무엇이 확인돼야 하는가 (검사 결과, 영양사 감수 등)?

## 프리오더 방식

1. **사전 신청 (결제 없음)**: 시제품 사진, 8개입 구성, 가격, 배송비 3,000원, "성분은 분석 후 표기 예정"을 적은 신청 페이지를 연다. 가격은 13,900원 / 14,900원 두 버전을 나눠 노출한다.
2. **구매 확약**: 신청자에게 "출시되면 결제하겠다"는 확약 여부를 묻는다.
3. **선결제는 사업자 등록·통신판매업 신고 확인 후** 2단계로 진행한다 (미확인 상태에서는 결제를 받지 않는다).

성분 수치는 검사 전에는 쓰지 않고 질병 치료·예방 효과를 내세우지 않는다. 신청 페이지는 인터뷰 대상자와 투석센터 소개를 통해 알린다.

## 제조사 문의 (5곳)

조건: **프리오더 배치 생산, 직배송, 공동 브랜드** 또는 소량 단독 OEM. 확인 항목은 최소 주문량, 개당 단가(포장 포함 여부), 사과 쌀쿠키 구운 쿠키 공정 가능 여부·펠렛 선가공 필요 여부, 성분 검사 협조·표시 책임, 샘플 비용·소량 시험 제조 조건이다. 제품 사진·배합표·목표 중량(40~60g)을 첨부한다. 행복생활에프앤비도 이 조건으로 재문의한다.

## 중단·진행 기준 (10/26 판단)

| 항목 | 진행 | 보류 | 중단 |
|---|---|---|---|
| 인터뷰 | 구매 의향이 과반 | 의향은 있으나 가격·성분 정보가 걸림 → 보완 후 재확인 | 구매 의향이 과반 미만 |
| 제조사 | 2곳 이상이 직배송·소량 배치에 동의하고 공급가 개당 약 1,300원 이하 (단독 OEM이면 최소 주문량 약 1,000개 이하·개당 약 1,070원 이하) | 1곳만 가능 → 추가 탐색 | 가능한 곳 없음 또는 공급가 약 1,500원 이상 |
| 사전 신청 | 신청 30세트 이상, 확약 과반 | 15~29세트 → 홍보 1주 연장 후 재집계 (1회) | 15세트 미만 |
| 가격 | 14,900원 버전의 신청이 13,900원 버전의 70% 이상이면 14,900원 채택 | - | - |

**하나라도 중단 기준에 해당하면 중단한다.** 모두 "진행"이면 BM을 확정하고 IR 자료와 문서를 갱신한다.
