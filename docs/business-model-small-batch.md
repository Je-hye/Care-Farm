# 5. 비즈니스 모델 및 수익 구조 — 소규모 직접 제작안 (Business Model, Small-batch)

> 이 문서는 `docs/business-model.md`(OEM 제조 기반안)와 별개로 작성한 **대안 BM**이다. 공유주방이나 카페 공간을 빌려 팀이 직접 소량 제작하고, 판매가 확인되면 제조처로 이전한다. 수치는 모두 `가정`이며 공유주방 요금·보건소 확인·성분 검사 견적·판매 데이터로 교체한다.

## 한 줄 요약

**선투자(재고·최소 주문량) 없이 직접 만들어 수요를 확인하는 저비용 검증 모델이다.** 직접 제작 단독으로는 수익이 거의 나지 않으며, 수익은 판매량이 확인된 뒤 제조처로 이전해 규모를 키운 이후에 기대한다.

| 항목 | 내용 |
|---|---|
| 고객 | 혈액투석 환자와 보호자 (1차 결제자는 보호자일 가능성) |
| 제품 | 사과 쌀쿠키 8개입 1종, 1개당·100g당 성분(나트륨·칼륨·인) 표기 |
| 제조 | 영업 신고가 가능한 공유주방·카페 공간을 빌려 직접 소량 제작 (월 최대 약 150세트, 팀 시간 기준 가정) |
| 채널 | ① 온라인 프리오더·정기배송 ② 환우회·투석센터 행사 등 오프라인 직접 판매 |
| 가격 | 일반구매 14,900원, 정기배송 13,900원 (배송비 3,000원 별도, 구매자 부담) |
| 전환 | 월 100~150세트가 2개월 이상 유지되면 제조처 최소 주문량을 협상하거나 이전 |

## 초기 투자 비용 및 자금 조달 계획

초기 비용은 총 **500만 원**으로 설정하며, 교내·외 창업지원사업을 통해 조달하는 것을 목표로 한다. 500만 원은 확보된 자금이 아닌 목표 예산이다.

### 투자 계획

| 투자 항목 | 예산 | 비고 |
|---|---|---|
| 핵심 성분 분석·전문 검토 | 120만 원 | 최종 후보 1종의 나트륨·칼륨·인·영양성분 |
| 시제품·소량 제작 (재료·포장·공간 대여) | 50만 원 | 프리오더 30세트(약 240개) 포함 |
| 고객 파일럿·프리오더 운영 | 50만 원 | 인터뷰 사례품, 신청 페이지, 행사 참가비 |
| 영업 신고·위생교육·통신판매업 신고 | 20만 원 | 아래 비용표 참고 |
| 포장 샘플·제품 설명자료 | 30만 원 | |
| 운영 손실 한도 (고정비 적자 대비) | 230만 원 | 누적 손실이 이 한도에 닿으면 중단·재평가 |
| **합계** | **500만 원** | |

### 3주 검증 단계 비용 (프리오더 30세트 = 약 240개, 검사 제외)

| 항목 | 금액 | 근거 |
|---|---|---|
| 재료비 (240개) | 약 9만 원 | 팀 추정 개당 380원 |
| 포장재 | 약 4만 원 | 개당 약 150원 (가정) |
| 공유주방·카페 공간 대여 | 약 12~36만 원 | 시간당 1.5~3만 원 × 8~12시간 (**가정, 확인 못 함**) |
| 영업 신고 수수료 | 약 3만 원 | 온라인 안내 기준 2만 8천 원 (지역별 상이) |
| 면허세 | 약 3~7만 원 | 온라인 안내 기준 2만 7천~6만 7,500원 |
| 통신판매업 신고 | 약 1~4만 원 | 등록면허세 연 1.2만~4.05만 원 (지역별 상이) |
| 보건증 | 약 0.3~0.6만 원 | 온라인 안내 기준 |
| 위생교육 | 약 1~3만 원 | 수수료 미확인, 신규 영업자 6시간 이수 |
| **소계** | **약 33~66만 원** | |

성분 검사(최대 120만 원)를 더하면 약 150~190만 원이다. 신고 업종에 따라 비용·조건이 달라지므로 관할 보건소 확인 후 확정한다.

> 위 요금은 온라인 검색으로 확인한 일반 안내이며 대구·경북 실제 요금과 다를 수 있다. 공유주방 대여 요금은 직접 문의로 교체한다.

## 제조·운영 방식

| 구분 | 내용 | 확인할 것 |
|---|---|---|
| 제조 장소 | 신고된 공유주방 또는 이용자 명의 신고가 가능한 카페·베이킹 공간 | 대구·경북 시설 3곳 이상 문의. 후보: 베이크베이크_동대구역(공유 베이킹 주방, 단기·장기 이용 소개) |
| 영업 신고 | 직접 만든 쿠키를 온라인·택배로 판매하는 데 필요한 업종 (제과점·즉석판매제조가공업 등) | 관할 보건소에서 업종과 시설 기준 확인 (쿠킹 스튜디오 대관은 신고 시설이 아닐 수 있음) |
| 표시·검사 | 원재료·알레르기·영양성분 표시, 성분 검사 | 판매 전에 갖춰야 할 표시 사항과 검사 항목 확인 |
| 생산 방식 | 프리오더로 선결제를 받은 만큼만 만들어 발송 | 선결제는 사업자 등록·통신판매업 신고 후 |
| 직접 판매 | 환우회·투석센터 행사, 지역 장터 | 센터·행사 주최 측의 판매·시식 허용 여부 |

## 수익 모델

| 수익 유형 | 가격 가설 | 설명 |
|---|---|---|
| D2C 일반구매 | 8개입 14,900원 (배송비 3,000원 별도) | 개당 약 1,863원. 기능성 간식(널담 할인가 개당 1,242~1,325원)보다 약 41~50% 높아 지불의사 검증이 필수 |
| D2C 정기배송 | 8개입 13,900원 (배송비 3,000원 별도) | 일반구매 대비 약 6.7% 할인. 재구매가 확인되면 도입 |
| 오프라인 직접 판매 | 8개입 14,900원 | 배송비·플랫폼 수수료가 없고 카드 수수료 약 2%. 판매 장소·시간에 묶임 |

모든 가격은 1차 가설이며 프리오더에서 13,900원 / 14,900원 버전 반응을 비교해 정한다.

## 원가·시나리오·손익분기점(BEP)

### ① 시나리오 가정

공통 가정: 일반구매 80%·정기배송 20%, 결제·플랫폼 수수료 4%, 배송비 구매자 부담, 판매 비중은 세트(8개) 기준.

| 구분 | 낙관안 | 기준안 | 보수안 |
|---|---|---|---|
| 개당 변동원가 | 800원 (재료 380 + 포장 150 + 공간 대여 200 + 폐기·시식 70) | 900원 (380 + 180 + 250 + 90) | 1,000원 (380 + 200 + 300 + 120) |
| 부가세 | 간이과세 실효 2% | 간이과세 실효 2% | 일반과세 10% |
| 월 고정비 (인건비 제외) | 약 100만 원 | 약 130만 원 | 약 160만 원 |
| 판매 곡선 (월별 세트) | 20→40→60→80→100→120 | 15→30→45→60→80→100 | 10→20→30→40→45→50 |
| 6개월 이후 월 판매 | 150세트 | 120세트 | 60세트 |

낙관안 월 고정비 구성: 공유주방 기본료·보관 20만 + 정기 성분 검사 30만 + 마케팅 30만 + 쇼핑몰·소프트웨어 5만 + 회계·세무 10만 + 기타 5만 원.

### ② 시나리오별 결과

| 구분 | 낙관안 | 기준안 | 보수안 |
|---|---|---|---|
| 세트당 공헌이익 (일반 / 정기) | 7,606원 / 6,666원 | 6,806원 / 5,866원 | 4,814원 / 3,954원 |
| 평균 세트당 공헌이익 | 약 7,418원 | 약 6,618원 | 약 4,642원 |
| **손익분기 판매량 (인건비 제외)** | **약 135세트** | **약 196세트** | **약 345세트** |
| 손익분기 판매량 (인건비 월 200만 원 포함) | 약 404세트 | 약 499세트 | 약 776세트 |
| 6개월 시점 월 손익 | 약 −11만 원 | 약 −64만 원 | 약 −137만 원 |
| 월 150세트 판매 시 월 손익 | 약 +11만 원 | 약 −31만 원 | 약 −90만 원 |
| 최대 누적 손실 (12개월 내) | 약 288만 원 (6개월차) | 약 865만 원 (적자 지속) | 약 1,662만 원 (적자 지속) |
| 12개월 시점 누적 손익 | 약 −221만 원 | 약 −865만 원 | 약 −1,662만 원 |

### ③ 해석

- 직접 제작 단독으로 BEP에 닿는 시나리오는 **낙관안뿐**이고, 그때도 월 150세트에서 이익이 월 약 11만 원이다. 기준안의 BEP(약 196세트)는 월 제작 한계(약 150세트)보다 높다.
- 낙관안도 판매가 천천히 늘기 때문에 12개월 누적은 약 −221만 원이다. 누적 손실이 운영 손실 한도(230만 원)에 닿는 시점은 낙관안 기준 약 4개월차이다.
- 따라서 이 BM은 **수익 모델이 아니라 검증 모델**이다. 목적은 구매 의사, 가격 수용도, 재구매 여부를 낮은 비용으로 확인하는 것이다.
- 인건비를 넣으면 BEP가 낙관안에서도 월 약 404세트이므로, 직접 제작 단계는 팀 무급 운영을 전제로 한다.

### ④ 월 고정비 항목 (낙관안, 인건비 제외)

| 항목 | 월 금액 | 비고 |
|---|---|---|
| 공유주방 기본료·보관 | 20만 원 | 가정 (요금 미확인) |
| 정기 성분 검사·품질관리 | 30만 원 | 소량 배치를 분기 단위로 묶어 검사 |
| 마케팅 (콘텐츠·샘플) | 30만 원 | 투석센터 소개·환우 커뮤니티 등 저비용 채널 |
| 쇼핑몰·소프트웨어·통신 | 5만 원 | 수수료형 쇼핑몰, 무료 도구 |
| 회계·세무 | 10만 원 | 자체 장부 + 연 1회 세무 점검 |
| 기타 | 5만 원 | |
| **합계** | **100만 원** | |

## 단계별 로드맵과 전환 조건

| 단계 | 기간 | 내용 | 다음 단계 조건 |
|---|---|---|---|
| 1. 검증 | 3주 | 인터뷰, 보건소 확인, 사전 신청(결제 없음), 제조 시설 문의 | 신청 30세트 이상, 영업 신고 가능, 구매 의향 과반 |
| 2. 직접 제작 판매 | 출시 후 0~6개월 | 프리오더 선결제 → 직접 제작·발송, 오프라인 행사 병행 | 월 100세트 이상 2개월 유지, 8주 재구매율 30% 이상 |
| 3. 제조처 이전 판단 | 출시 후 6~12개월 | 판매량을 근거로 제조처 최소 주문량·단가 협상 | 개당 단가가 직접 제작보다 낮고 최소 주문량 선투자가 한도 이내 |
| 4. 확장 | 12개월 이후 | 정기배송, 기관 연계, 필요 시 원료·배합 사업화 탐색 | 단위 경제성 확인 후 판단 |

## 단계별 진행·중단 기준

아래 기준은 제안값이다.

| 단계 | 진행 조건 | 중단·재설계 기준 |
|---|---|---|
| 검증 | 구매 의향 과반, 사전 신청 30세트 이상, 영업 신고와 제조 장소 확보 | 구매 의향 과반 미만, 신청 15세트 미만, 영업 신고 불가 중 하나라도 해당하면 중단 |
| 직접 제작 판매 | 월 판매가 곡선에 맞게 증가, 누적 손실이 한도(230만 원) 이내 | 누적 손실이 230만 원에 닿으면 중단하거나 제조처 이전·가격 재설정 여부를 판단 |
| 제조처 이전 | 월 100세트 이상 2개월 유지, 재구매율 30% 이상 | 판매가 정체되면 직접 제작 규모로 유지하거나 종료 |

## 지표 산정 기준

| 지표 | 산정 방식 |
|---|---|
| 사전 신청 세트 | 신청 페이지 신청 수량을 8개입 기준으로 환산. 구매 확약 여부를 별도 집계 |
| 8주 재구매율 | 첫 유료 구매 후 56일 이내 재구매 고객 수 ÷ 56일 관찰이 끝난 첫 구매 고객 수. 무료 시식·취소 주문 제외 |
| 세트당 공헌이익 | 판매가 − 부가세 − 결제수수료 − 변동원가(재료·포장·공간 대여·폐기). 배송비는 구매자 부담 |
| 손익분기 판매량 | 월 고정비 ÷ 세트당 평균 공헌이익. 인건비는 제외하고 포함 시 별도 산정 |
| 운영 손실 한도 | 출시 후 월 손익의 누적 합계가 −230만 원에 닿는 시점 |
