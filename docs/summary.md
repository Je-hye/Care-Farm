# Care-Farm 한 장 요약 (선택안·근거·검증 질문·일정)

> 세부 내용은 `docs/business-model-impact.md`(임팩트 중심안), `docs/business-model-small-batch.md`(소규모 직접 제작안), `docs/business-model.md`(OEM 제조안), `docs/verification-plan.md`(3주 검증 계획)를 참고한다. 수치는 모두 `가정`이며 견적·확인 후 교체한다. (작성 기준일 2026-10-05)

## 선택안

**임팩트 중심 BM + 소규모 직접 제작(검증 수단) + 졸업 후 식품 기업 이관(목표).**

| 요소 | 내용 |
|---|---|
| 목적 | 혈액투석 환자·보호자의 성분 정보 접근성과 간식 선택권 개선 (건강 효과는 주장하지 않음) |
| 제품 | 사과 쌀쿠키 8개입 1종, 1개당·100g당 성분 표기 (성분 수치는 검사 후에만 표기) |
| 가격 | 일반구매 14,900원, 정기배송 13,900원 (프리오더에서 13,900원 버전과 비교) |
| 제조 | 영업 신고가 가능한 공유주방·카페 공간에서 직접 소량 제작. 소량 제조처·위탁 구조는 병행 탐색 |
| 채널 | 온라인 프리오더·정기배송, 환우회·투석센터 행사 |
| 재원 | 판매(운영비 일부 충당) + 지원사업·후원 |
| 출구 | **목표:** 식품 기업이 상품화 (임팩트 유지 조건 협상) / **보험:** 병원 영양팀·환우회 → 학교 → 자료 공개 |

## 선택 근거

| 비교 | 결과 |
|---|---|
| 수익 | 직접 제작 단독은 낙관안도 월 150세트에서 월 약 +11만 원, 12개월 누적 약 −221만 원. 수익 목적에는 부족 |
| 위험 | 운영 손실 한도 230만 원, 검증 단계에서 중단 가능. OEM안은 최소 주문량 약 6,000개로 1회 생산 선투자가 약 564만 원 |
| 정합 | 임팩트 목적은 지원사업·후원과 맞고, 졸업 후 이관 전제와도 맞음 |
| 한계 | 지원·후원 확보, 영업 신고, 구매 의향, 이관 의사가 모두 미확인 |

## 3주 검증 질문 4가지 (10/6~10/26)

| # | 질문 | 확인 방법 | 진행 기준 (제안) |
|---|---|---|---|
| 1 | 환자·보호자가 살 이유와 가격 수용도가 있는가 | 환자 8~10명·보호자 약 5명 인터뷰, 사전 신청(13,900원/14,900원 비교) | 구매 의향 과반, 사전 신청 30세트 이상 |
| 2 | 직접 제작·판매가 가능한가 | 관할 보건소(영업 신고 업종·시설), 공유주방 문의 3곳 | 영업 신고와 제조 장소 확보 |
| 3 | 후원·지원을 받을 수 있는가 | 대구사회적기업지원센터·소셜캠퍼스 온 대구·경북대 창업지원단 상담, 공고 확인 | 신청 가능한 공고 1건 이상 |
| 4 | 기업이 이어받을 의향이 있는가 | 제조사 5곳 문의 (상품화·공동 개발 의향, 임팩트 유지 조건 반응 포함) | 관심 보이는 곳 1곳 이상 |

## 일정

| 주차 | 기간 | 할 일 |
|---|---|---|
| 1주 | 10/6~10/12 | 질문지 확정, 인터뷰 섭외, 제조사 5곳·공유주방·보건소 문의, 사전 신청 페이지 초안 |
| 2주 | 10/13~10/19 | 인터뷰, 영양사 검토, 지원 기관 상담, 사전 신청 공개 |
| 3주 | 10/20~10/26 | 결과 집계, 10/26 진행·보류·중단 결정 |

결과는 HERO IR(11/2) 자료에 반영한다.

## 중단·진행 판단 (10/26)

| 결과 | 판단 |
|---|---|
| 4개 중 3개 이상 기준 충족 | 진행: 직접 제작 판매 시작, 이관 준비 병행 |
| 구매 의향·사전 신청 기준은 충족하나 영업 신고·지원·이관 중 일부 미확인 | 보류: 해당 항목 보완 후 재판단 (1회) |
| 구매 의향 과반 미만, 사전 신청 15세트 미만, 영업 신고 불가 중 하나 | 중단: 성분 설계·인터뷰 자료를 정리·공개하는 방식으로 전환 |

## 비용 상한과 손실 한도

- 3주 검증: 검사 제외 약 33~66만 원, 성분 검사 포함 시 약 150~190만 원 (공유주방 요금은 확인 전 가정)
- 출시 후 운영 손실 한도: 230만 원 (누적 손실이 닿으면 중단·재평가)
- 초기 비용 총 500만 원은 확보된 자금이 아닌 목표 예산

## 알아둘 점

- 인건비는 0원 가정이다. 인건비를 넣으면 손익분기 판매량이 월 약 404세트 이상이라 직접 제작 단계는 팀 무급 운영이 전제다.
- 사업자 등록·통신판매업 신고·선결제는 지원사업의 예비창업자 자격 조건과 충돌할 수 있어, 공고 조건을 확인한 뒤 시점을 정한다.
- 표시·광고는 질병 예방·치료 효과를 표방하지 않고, 성분은 검사 결과 기준으로만 표기한다.
- 연구실은 확인하지 못했으며, 알려 주신 연구실 이름이 있으면 협력·이관 후보로 반영한다.
